# Hexa

Hexa is a programming language and a compiler for it.

Homepage: https://hexalang.org

GitHub: https://github.com/hexalang/hexa

## Hexa JSON

Hexa's `hexa.json` is a configuration file for Hexa projects and the Hexa compiler.

Full reference: https://hexalang.org/Hexa/hexa.json.html

## Hexa Syntax Reference

Hexa's syntax is curly-brace based, with deep notion of declarative code flow.

Full reference: https://hexalang.org/Hexa/reference.html

## Hexa Native Programming

Hexa can be used to write native code for various platforms with its low-level features.

Full reference: https://hexalang.org/Hexa/native.html
